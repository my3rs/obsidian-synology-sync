# Obsidian Synology Sync

[English](README.md)

通过群晖官方 Drive API 将您的 Obsidian 笔记库与群晖 (Synology) NAS 进行同步。此插件提供了一种安全可靠的方式，将您的 Obsidian 笔记直接备份和同步到群晖中，而无需依赖任何第三方云服务中转。

### 功能特点
- 基于**群晖官方 WebAPI**（Synology Drive API）直接打通，更加原生、官方且安全。
- 支持双向同步、仅上传和仅下载模式。
- 采用直接鉴权，账号密码仅用于在本地直接请求您的群晖 NAS 进行官方登录，全程无第三方数据收集。
- 多语言支持（英文和中文）。

### 安装说明

**首选方式：通过官方社区插件商店安装（推荐）**
1. 在 Obsidian 中打开**设置** -> **第三方插件**。
2. 关闭**安全模式**。
3. 点击**浏览**，搜索 `Synology Sync`。
4. 点击**安装**，安装完成后启用该插件。

*注意：本插件目前可能正处于上架审核期间。如果您在官方商店暂时搜不到，或需要测试最新内测版，请使用以下任意一种备选方式。*

<details>
<summary>备选方式一：使用 BRAT 安装（用于内测版体验）</summary>

1. 在 Obsidian 的“社区插件”中搜索并安装 **Obsidian42 - BRAT** 插件，并启用它。
2. 打开 BRAT 插件设置界面，点击 **Add Beta plugin**。
3. 粘贴本项目的 GitHub 仓库地址：`seahi/obsidian-synology-sync` （或你的完整仓库链接）。
4. 添加完成后，在 Obsidian 的“第三方插件”列表中将其启用即可。

</details>

<details>
<summary>备选方式二：手动安装</summary>

1. 前往本项目的 [Releases 页面](../../releases/latest) 下载最新版本的发布包（需包含 `main.js`, `manifest.json`, `styles.css` 三个文件）。
2. 在您的 Obsidian 笔记库目录中，找到 `.obsidian/plugins/` 文件夹（如果没有则手动创建一个）。
3. 在该目录下新建一个名为 `obsidian-synology-sync` 的文件夹。
4. 将下载的 3 个文件放入刚才新建的文件夹中。
5. 重启 Obsidian，并在设置的“第三方插件”中启用本插件。

</details>

### 配置指南
1. 进入 "Synology Sync" 设置选项卡。
2. 输入您的群晖 NAS 地址（例如：`https://your-nas-ip:5001`）。
3. 输入您的群晖用户名和密码。
4. 测试连接并开始同步！
